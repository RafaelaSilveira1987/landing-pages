# Landing Page Humanizada - Cuidar no Lar

Versão criada para fugir do padrão comum de landing page e vender cuidado de forma mais humana, simples e acolhedora.

## Arquivos

- `index.html`
- `assets/css/styles.css`
- `assets/js/app.js`

## Características

- HTML, CSS e JavaScript puro
- Fonte mais leve: Nunito Sans
- Visual com tons de cuidado: teal, creme, verde suave e papel
- Linguagem simples para todas as idades
- Formulário que abre mensagem pronta no WhatsApp
- Menu responsivo
- Animações leves ao rolar a página

## Ajustes importantes

Troque o número de WhatsApp em `index.html` e `assets/js/app.js`, se necessário.
