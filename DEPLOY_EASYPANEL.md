# Publicação no EasyPanel

1. Envie todos os arquivos desta pasta para a raiz do repositório GitHub.
2. Confirme que `Dockerfile` aparece no mesmo nível de `index.html`.
3. No EasyPanel, mantenha o caminho do Dockerfile como `Dockerfile`.
4. Faça um novo deploy.
5. A porta interna do container é `80`.

Estrutura esperada:

```text
Dockerfile
nginx.conf
index.html
style.css
assets/
```
