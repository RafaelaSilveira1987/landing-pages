# RS Digital Lab — Portfólio pensado primeiro para celular

Nova versão da página principal de projetos da RS Digital Lab.

## Principais mudanças

- Rebranding de **RS Automação Digital** para **RS Digital Lab**.
- Nova logo aplicada em versões para fundo claro e fundo escuro.
- Estrutura criada primeiro para celular e depois ajustada para telas maiores.
- Cabeçalho compacto com menu fácil de usar no celular.
- Primeira seção mais clara, atraente e ligada aos serviços da empresa.
- Área com 6 projetos reais, links ativos e botões para separar por categoria.
- Imagens de exemplo criadas dentro do próprio projeto, sem depender de arquivos externos.
- Seções de serviços, forma de trabalho, benefícios, dúvidas e contato.
- Formulário que organiza os dados e abre o WhatsApp.
- Formatação automática do telefone e movimentos suaves, com opção de reduzir animações.
- Informações preparadas para mecanismos de busca e compartilhamento em redes sociais.
